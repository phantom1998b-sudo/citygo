# CityGo الأردن

واجهة PWA باللغة العربية (من اليمين إلى اليسار) بخط Cairo ودعم safe areas للهواتف، تربط كباتن النقل بطلبات نقل الركاب والبضائع بين محافظات الأردن. تتضمن تسجيل ودخول الكباتن، مراجعة إدارية للطلبات، وإصدار رقم عمل بعد الموافقة.

## التشغيل

1. انسخ `.env.example` إلى `.env`.
2. أضف مفتاح Supabase العام (publishable/anon) إلى `VITE_SUPABASE_ANON_KEY`. عنوان المشروع مضبوط على `https://qfpcjarwaoohhdvdwzzb.supabase.co`.
3. شغّل ترحيلي قاعدة البيانات بالترتيب من محرر SQL في Supabase:
   - `supabase/migrations/202611020001_captain_onboarding.sql`
   - `supabase/migrations/202611020002_captain_dispatch.sql`
   - `supabase/migrations/202611020003_wallet_and_admin.sql`
   - `supabase/migrations/202611020004_safe_admin_return.sql`
   - `supabase/migrations/202611020005_restrict_rpc_grants.sql`
   - `supabase/migrations/202611020006_phone_email_login.sql`
   - `supabase/migrations/202611020007_valid_phone_login_email.sql`
4. فعّل تسجيل الدخول بالبريد وكلمة المرور من `Authentication → Providers → Email`، وعطّل خيار تأكيد البريد الإلكتروني لأن عنوان الدخول الداخلي لا يستقبل رسائل. لا يحتاج تسجيل الكباتن الجدد إلى مزود SMS.
5. أنشئ حساباً للمشرف في `Authentication → Users` (مع رقم هاتف وكلمة مرور)، ثم أضف معرّف المستخدم إلى جدول `public.admin_users` من لوحة Supabase:

   ```sql
   insert into public.admin_users (user_id)
   values ('AUTH_USER_UUID');
   ```

   جدول المشرفين محمي بسياسات RLS، ولا يمكن للمستخدم إضافة نفسه إلى قائمة المشرفين.
6. شغّل `npm.cmd install` ثم `npm.cmd run dev`. أنشئ إصدار الإنتاج عبر `npm.cmd run build`.

لا تضع مفتاح `service_role` في تطبيق المتصفح أو في ملف `.env` الخاص بالواجهة. يستخدم التطبيق المفتاح العام فقط، وتفرض قاعدة البيانات وسياسات التخزين صلاحيات المشرف والملفات.

## سلوك التسجيل

- يقبل التسجيل أرقام الهاتف الأردنية ويحوّلها إلى صيغة `+962`.
- يحوّل التطبيق رقم الهاتف إلى بريد دخول داخلي بالشكل `962791234567@login.citygo.app` وينشئ حساب Email/Password حقيقياً في Supabase؛ لا يحتاج الكابتن لإدخال البريد أو استلام SMS. يسجّل الدخول برقم الهاتف نفسه والرمز السري.
- يُخزّن الرمز السري عبر Supabase Auth ولا يُحفظ كنص عادي في سجل الكابتن. تسجيل الحساب بهذه الطريقة لا يثبت ملكية رقم الهاتف؛ تتحقق الإدارة من بيانات ووثائق الكابتن قبل الموافقة.
- يستمر دعم تسجيل الدخول للحسابات القديمة المسجلة عبر مزود الهاتف، لذلك اترك مزود Phone مفعلاً إلى أن تُرحّل الحسابات القديمة. تتطلب سياسة إدخال طلب التسجيل ترحيل `202611020006_phone_email_login.sql`.
- يمكن رفع الهوية ورخصة القيادة ورخصة المركبة كصور أو PDF (حتى 8 ميغابايت لكل ملف). تُحفظ الملفات في حاوية خاصة، ولا يستطيع عرضها إلا الكابتن صاحبها والمشرف.
- تُنشأ الطلبات بحالة «قيد المراجعة». لا يمكن للكابتن تغيير حالة الطلب أو رقم عمله؛ الموافقة والرفض متاحان عبر دالة قاعدة بيانات تتحقق من صلاحية المشرف.
- يولّد النظام رقم العمل داخل قاعدة البيانات عند الموافقة، وليس في المتصفح.

تُخزّن واجهة التطبيق وملفاتها الثابتة مؤقتاً لإتاحة شاشة التطبيق دون اتصال. يتطلب تسجيل الدخول ورفع الطلبات ومراجعتها اتصالاً بالشبكة.

تعرّف `public/manifest.webmanifest` التطبيق بوضع `standalone`، ويسجّل `src/main.tsx` عامل الخدمة في إصدار الإنتاج فقط. يعمل تخطيط RTL على الشاشات الصغيرة مع خط Cairo وخطوط احتياطية. تتطلب خطوط Google اتصالاً أولياً بالإنترنت، وتبقى خطوط النظام الاحتياطية متاحة عند انقطاعه.

## تشغيل الكابتن

- بعد الموافقة، تعرض الصفحة الرئيسية اسم الكابتن الأول والأخير ورقم العمل وبيانات المركبة.
- مفتاح «متصل/غير متصل» يوقف قبول الطلبات الجديدة أو يعيد فتحه. تصل طلبات الركاب الحية عبر Supabase Realtime، مع تحديث احتياطي كل ١٢ ثانية. عند الاتصال، يطلب التطبيق إذن إشعارات المتصفح ويفعّل تنبيهاً صوتياً لطلبات الركاب الجديدة المنشورة من كابتن آخر؛ يجب إبقاء التطبيق مفتوحاً لاتصال Realtime. لا يوجد حالياً نموذج أو جدول مستقل لطلبات البضائع. يدعم عامل الخدمة عرض إشعار Push إذا أرسله مزود Push، لكن إرسال Push في الخلفية عند إغلاق التطبيق يتطلب إعداد اشتراكات Web Push ومفاتيح VAPID وخدمة إرسال على الخادم، وهو غير مهيأ في هذا الإصدار.
- ينشئ الكابتن طلب الركاب بالسعر، المحافظات والمناطق، عدد الركاب أو السيارة الكاملة، الموعد، ورقم الراكب. لا يظهر رقم الراكب إلا لمضيف الطلب أو الكابتن الذي قبله أو المشرف.
- يقبل الكابتن الطلب بعد خطوة تأكيد. تحجز الطلبات النشطة حتى أربعة مقاعد؛ السيارة الكاملة تحجزها كلها. لا يملك الكابتن إلغاء الطلب بعد قبوله، وتحرر المقاعد عند إتمام التوصيل. الإلغاء متاح للمشرف فقط من لوحة الإدارة.
- بعد القبول يظهر زر واتساب للراكب. رقم الراكب محفوظ في جدول خاص منفصل، وليس ضمن سجل الطلبات المبثوث لحظياً للكباتن.
- يحصل الكابتن على 5 د.أ عند الموافقة. رسوم طلب الراكب العادي على الكابتن المستلم هي 0.50 د.أ لكل مقعد + 0.75 د.أ للطلب؛ والسيارة الكاملة 1 د.أ + 0.75 د.أ للطلب. عند اكتمال الرحلة، يحصل منشئ الطلب العادي على 0.75 د.أ لكل مقعد + 1 د.أ للطلب؛ والسيارة الكاملة تحصل على 2 د.أ.
- يخصم رسم القبول عند إسناد الرحلة لتأكيد كفاية الرصيد، ويعاد تلقائياً إذا أعاد المشرف الطلب إلى اللوحة قبل إتمامه. تضاف عمولة منشئ الطلب فقط بعد ضغط الكابتن المستلم زر إتمام التوصيل.
- طلبات شحن المحفظة ترفع إشعار التحويل إلى تخزين خاص وترسله كملاحظة خاصة للإدارة؛ لا يتغير الرصيد قبل اعتماد المشرف. لا يستطيع المستخدم تعديل دفتر المعاملات.
- تُقدّم طلبات السحب وتُعالج أيام الاثنين والخميس بتوقيت الأردن، مع حجز قيمة الطلبات المعلقة وإبقاء حد أدنى قدره 5 د.أ بعد كل سحب.
- لوحة الإدارة موصولة بحسابات المشرف المعتمدة على المسار غير المدرج `/citygo-admin`، وتضم مراجعة الكباتن والرحلات النشطة وأرصدة المحافظ وطلبات الشحن والسحب. لا يظهر رابطها للزوار أو الكباتن، كما تتحقق قاعدة البيانات من صلاحية المشرف لكل إجراء.
